# Pengembangan Digital Twin UMKM Warung Bu Pita

## Monitoring Produksi, Persediaan, dan Penjualan

### Kelompok 13

Repository ini berisi dokumentasi dan hasil pengerjaan proyek pengembangan Digital Twin UMKM pada Warung Bu Pita untuk mendukung monitoring produksi, persediaan, dan penjualan.

## Tujuan Proyek

Proyek ini bertujuan untuk mengembangkan konsep Digital Twin yang dapat membantu proses monitoring aktivitas warung secara lebih terstruktur, khususnya pada aspek produksi, persediaan, dan penjualan.
